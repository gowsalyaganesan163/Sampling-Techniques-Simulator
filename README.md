
# Sampling Techniques Simulator

A Python-based interactive simulator designed to explore and understand different statistical sampling techniques. The project demonstrates how sampling methods work, compares sample distributions with population characteristics, and helps visualize sampling behavior.

## Features

- Random sampling
- Stratified sampling
- Systematic sampling
- Cluster sampling
- Population and sample generation
- Sample visualization and display
- Sampling error analysis
- Bias analysis
- Sampling technique comparison

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/Sampling-Techniques-Simulator.git
```

Navigate to the project directory:

```bash
cd Sampling-Techniques-Simulator
```

Install the required dependencies if a requirements file is available:

```bash
python -m pip install -r requirements.txt
```

## Usage

Run the simulator:

```bash
python main.py
```

Follow the terminal instructions to explore the sampling techniques and their comparisons.

## Purpose

This project was developed to strengthen understanding of statistical sampling, sampling distributions, representativeness, bias, and sampling error through Python programming.
